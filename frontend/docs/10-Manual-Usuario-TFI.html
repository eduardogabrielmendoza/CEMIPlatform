1. Introducción

El presente manual de usuario tiene como objetivo brindar una guía clara, ordenada y accesible para el uso del Sistema de Gestión Académica CEMI. Este sistema fue desarrollado con el fin de optimizar y digitalizar los procesos académicos, administrativos y de comunicación del Centro de Estudios Multilingüe Internacional.

A través de este manual, el usuario podrá comprender el funcionamiento de cada módulo, identificar las acciones disponibles y realizar todas las operaciones necesarias de manera segura y eficiente.

1.1 Propósito del Manual

  • Explicar detalladamente cómo navegar y utilizar cada sección del sistema.
  • Ofrecer instrucciones paso a paso para la correcta gestión de alumnos, cursos, pagos y calificaciones.
  • Facilitar el aprendizaje de nuevos usuarios y servir como material de consulta.
  • Garantizar que el uso del sistema se realice siguiendo las buenas prácticas establecidas.

1.2 Audiencia

Administradores

  • Configurar datos principales
  • Gestionar usuarios
  • Revisar estadísticas
  • Administrar pagos
  • Control total del sistema

Profesores

  • Gestionar cursos asignados
  • Publicar tareas y anuncios
  • Calificar alumnos
  • Registrar asistencias
  • Chat con alumnos

Alumnos

  • Consultar inscripciones
  • Ver calificaciones
  • Entregar tareas
  • Ver pagos y comprobantes
  • Chat con profesores

2. Requisitos para Acceder al Sistema

Antes de ingresar al sistema, el usuario debe cumplir con los siguientes requisitos:

  • Poseer un usuario y contraseña registrados con email institucional (@cemi.com para staff).
  • Contar con conexión a Internet.
  • Tener acceso a un dispositivo compatible (PC, Notebook, Tablet o Smartphone) con navegador actualizado (Google Chrome recomendado).
  • Haber activado la cuenta mediante el enlace enviado por email tras el registro.

3. Pantalla de Inicio de Sesión

3.1 Descripción General

La pantalla de inicio de sesión permite al usuario autenticarse mediante sus credenciales personales. El acceso está protegido mediante un mecanismo de autenticación basado en JWT (JSON Web Token).

3.2 Elementos de la Interfaz

  • Campo "Correo electrónico" — Permite ingresar el email registrado. Es obligatorio.
  • Campo "Contraseña" — Incluye ícono para mostrar/ocultar la contraseña.
  • Botón "Ingresar" — Ejecuta la validación de credenciales y redirige según el rol.
  • Enlace "¿Olvidaste tu contraseña?" — Inicia el proceso de recuperación por email con código.
  • Botón "Crear Cuenta" — Redirige al formulario de registro.

3.3 Procedimiento de Inicio de Sesión

1

Ingresar correo electrónico

Escribir el email registrado en el campo correspondiente.

2

Ingresar contraseña

Escribir la contraseña asociada al usuario.

3

Presionar "Ingresar"

El sistema valida las credenciales y genera un token JWT.

4

Redirección automática

Si las credenciales son válidas, se redirige al dashboard correspondiente: admin, profesor o alumno.

3.4 Registro de Usuario

Para crear una nueva cuenta, el usuario debe completar:

  • Nombre completo — Nombre y apellido.
  • Correo electrónico — Debe ser válido y no estar previamente registrado. El dominio @cemi.com está reservado para staff.
  • Contraseña — Debe cumplir requisitos mínimos de seguridad.
  • Confirmar contraseña — Debe coincidir con la anterior.

Tras el registro exitoso, se enviará un email con enlace de activación. El usuario debe hacer clic en el botón verde "ACTIVAR CUENTA" para completar el proceso.

3.5 Recuperar Contraseña

1

Hacer clic en "¿Olvidaste tu contraseña?"

Se abre el modal de recuperación de acceso.

2

Ingresar email registrado

Hacer clic en "Enviar código".

3

Revisar correo

Se recibe un código de verificación.

4

Ingresar código + nueva contraseña

Hacer clic en "Confirmar" para restablecer el acceso.

4. Panel Administrativo

4.1 Descripción General

El panel administrativo es el centro de control del sistema. Solo accesible para usuarios con rol admin o superadmin. Desde aquí se gestionan todos los módulos del sistema.

4.2 Dashboard

Al ingresar, el administrador visualiza un dashboard con estadísticas generales:

  • Total de alumnos activos.
  • Total de profesores activos.
  • Total de cursos disponibles.
  • Inscripciones recientes.
  • Pagos pendientes y completados.
  • Conversaciones de chat activas.

5. Módulo Alumnos

5.1 Descripción General

Permite gestionar el registro completo de alumnos del centro. Cada alumno tiene un legajo único generado automáticamente, datos personales vinculados a la tabla personas y estado activo/inactivo.

5.2 Operaciones Disponibles

+

Registrar nuevo alumno

Completar nombre, apellido, email, DNI, teléfono. El sistema genera legajo automáticamente (A001, A002...).

✎

Editar datos del alumno

Modificar datos personales, domicilio, fecha de nacimiento, biografía.

👁

Ver perfil completo

Visualizar inscripciones, pagos, calificaciones y asistencias del alumno.

⊘

Cambiar estado

Activar o desactivar alumno sin eliminar su historial.

7. Módulo Cursos

Administración de cursos con asignación de idioma, nivel, profesor, aula, horario y cupo máximo. Los cursos tienen cuotas habilitadas configurables en formato JSON.

Importante: El campo cuotas_habilitadas define qué conceptos de pago están disponibles para cada curso (Matrícula, Marzo, Abril, etc.). Si es null, todas las cuotas están habilitadas.

8. Módulo Pagos

8.1 Descripción General

El módulo de pagos permite registrar, consultar y gestionar los pagos de los alumnos. Soporta múltiples medios de pago y genera comprobantes en PDF automáticamente.

8.2 Medios de Pago

IDMedio de Pago
1Efectivo
2Transferencia
3Tarjeta de Crédito

8.3 Procedimiento de Registro de Pago

1

Seleccionar alumno y curso

Buscar al alumno y elegir el curso al que corresponde el pago.

2

Seleccionar concepto

Elegir entre Matrícula o Cuota Mensual según las cuotas habilitadas.

3

Indicar monto y medio de pago

Ingresar el monto y seleccionar efectivo, transferencia o tarjeta.

4

Confirmar pago

El sistema registra el pago y genera un comprobante PDF descargable.

8.4 Estados de Pago

EstadoDescripción
en_procesoPago pendiente de confirmación
pagadoPago confirmado y registrado
anuladoPago anulado por administrador

9. Módulo Classroom

9.1 Descripción General

El módulo Classroom constituye el entorno virtual de aprendizaje del sistema. Permite a los profesores publicar contenido académico y a los alumnos interactuar con el material de sus cursos.

9.2 Funcionalidades del Profesor

Tareas

  • Crear tareas con descripción
  • Establecer fecha límite
  • Adjuntar archivos/enlaces
  • Revisar entregas
  • Calificar y comentar

Anuncios

  • Publicar anuncios al curso
  • Marcar como importante
  • Adjuntar enlaces
  • Crear encuestas
  • Ver comentarios

Evaluación

  • Registrar calificaciones
  • Parcial 1, Parcial 2, Final
  • Tomar asistencia diaria
  • 4 estados de asistencia
  • Historial completo

9.3 Funcionalidades del Alumno

  • Ver tareas asignadas — Listado de tareas con fecha límite y estado de entrega.
  • Entregar tareas — Subir archivos o escribir contenido de entrega.
  • Ver calificaciones — Consultar notas de entregas, parciales y final.
  • Leer anuncios — Ver anuncios del curso y comentar.
  • Responder encuestas — Participar en encuestas creadas por el profesor.
  • Chat con profesor — Comunicación directa mediante el chat de Classroom.
  • Chat entre alumnos — Comunicación con compañeros del mismo curso.
  • Calendario — Ver eventos y notas personales del calendario.

10. Chat de Soporte

10.1 Descripción General

El sistema de chat permite la comunicación en tiempo real entre usuarios y administradores. Implementado con Socket.IO para conexiones bidireccionales instantáneas.

10.2 Tipos de Usuario en el Chat

TipoDescripción
InvitadoPuede iniciar conversación sin estar registrado
AlumnoChat vinculado a su cuenta de alumno
ProfesorChat vinculado a su cuenta de profesor
AdminAtiende las conversaciones entrantes

10.3 Estados de Conversación

EstadoDescripción
PendienteConversación iniciada, esperando atención
ActivaConversación siendo atendida por un admin
ResueltaConsulta resuelta satisfactoriamente
CerradaConversación finalizada

10.4 Funcionalidades

  • Mensajes en tiempo real con Socket.IO.
  • Soporte para archivos adjuntos (imágenes y PDF).
  • Contador de mensajes no leídos.
  • Estadísticas de atención (tiempo de respuesta, calificación).
  • Historial de conversaciones persistente.

11. Barra de Navegación

La barra superior del sistema contiene los siguientes elementos según el rol del usuario:

Elementos Comunes

  • Logo CEMI — Enlace a la página principal.
  • Notificaciones — Campana con contador de notificaciones no leídas.
  • Perfil de usuario — Menú desplegable con opciones de cuenta.
  • Cerrar sesión — Elimina el token JWT y redirige al login.
