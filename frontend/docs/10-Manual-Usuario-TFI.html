1. Introducción

El presente manual tiene como objetivo brindar una guía clara y ordenada para el uso del Sistema de Gestión Académica CEMI. El sistema fue desarrollado para digitalizar y optimizar los procesos académicos, administrativos, financieros y comunicacionales del Centro de Estudios Multilingüe Internacional.

A través de este manual, los usuarios pueden comprender el funcionamiento de cada módulo, identificar las acciones disponibles y operar la plataforma de manera segura y eficiente.

1.1 Propósito del Manual

  • Explicar cómo navegar y utilizar cada sección del sistema.
  • Ofrecer procedimientos paso a paso para la gestión de alumnos, profesores, cursos, pagos, calificaciones y classroom.
  • Facilitar el aprendizaje de nuevos usuarios.
  • Garantizar buenas prácticas de uso y seguridad.

1.2 Audiencia

Administradores

  • Gestionan datos principales
  • Administran usuarios
  • Registran pagos
  • Atienden soporte
  • Consultan reportes

Profesores

  • Administran cursos asignados
  • Publican tareas y anuncios
  • Registran calificaciones
  • Toman asistencia
  • Chatean con alumnos

Alumnos

  • Consultan cursos
  • Ven pagos y comprobantes
  • Entregan tareas
  • Consultan calificaciones
  • Participan en comunidad

2. Requisitos para Acceder al Sistema

  • Poseer una cuenta registrada y activada.
  • Contar con conexión a Internet.
  • Utilizar un navegador moderno, preferentemente Google Chrome, Microsoft Edge o Firefox.
  • Acceder desde PC, notebook, tablet o teléfono con resolución compatible.
  • No compartir credenciales de acceso.

2.1 Acceso al Sistema

Para ingresar, el usuario debe abrir la dirección oficial del sistema: https://cemi.up.railway.app. Desde la página principal puede seleccionar el acceso correspondiente: general, administrativo o CEMI Key según el flujo requerido.

3. Inicio de Sesión y Registro

3.1 Descripción General

La pantalla de inicio de sesión permite autenticar al usuario con correo electrónico y contraseña. Si las credenciales son correctas, el sistema genera una sesión segura y redirige al dashboard correspondiente según el rol.

3.2 Elementos de la Interfaz

  • Campo Correo electrónico: permite ingresar el email registrado.
  • Campo Contraseña: permite ingresar la clave personal y mostrar u ocultar su contenido.
  • Botón Ingresar: valida las credenciales y abre la sesión.
  • Enlace Olvidaste tu contraseña: inicia el proceso de recuperación.
  • Botón Crear Cuenta: abre el registro de nuevos usuarios.

3.3 Procedimiento de Inicio de Sesión

1

Ingresar correo

Escribir el correo electrónico registrado en el campo correspondiente.

2

Ingresar contraseña

Completar la contraseña asociada a la cuenta.

3

Presionar Ingresar

El sistema valida datos obligatorios, formato de correo, existencia del usuario y coincidencia de contraseña.

4

Acceder al panel

Si los datos son válidos, se redirige al dashboard de alumno, profesor o administrador.

3.4 Registro de Usuario

Para crear una cuenta nueva, el usuario debe completar nombre, correo electrónico, contraseña y confirmación de contraseña. El sistema valida que el correo sea válido, que no esté registrado y que las contraseñas coincidan.

Luego del registro, se envía un correo de activación. La cuenta debe activarse desde el enlace recibido antes de iniciar sesión.

3.5 Recuperar Contraseña

1

Abrir recuperación

Hacer clic en Olvidaste tu contraseña.

2

Enviar código

Ingresar el correo registrado y solicitar el código de recuperación.

3

Revisar correo

Copiar el código recibido en el email personal.

4

Confirmar nueva contraseña

Ingresar el código, definir la nueva contraseña y confirmar el cambio.

4. Panel Administrativo

4.1 Descripción General

El panel administrativo concentra las herramientas de gestión del sistema. Está disponible para administradores autorizados y permite operar módulos académicos, financieros, comunicacionales y de configuración.

4.2 Dashboard

Al ingresar, el administrador visualiza indicadores generales y accesos rápidos. Según los permisos asignados puede consultar alumnos activos, profesores, cursos, inscripciones, pagos, conversaciones, reportes y estado del sistema.

4.3 Menú de Navegación

ProfesoresRegistro, especialidades, idiomas y cursos asignados.
CursosIdiomas, niveles, aulas, cupos, horarios y cuotas habilitadas.
InscripcionesAlta y consulta de alumnos inscriptos por curso.
PagosRegistro de cuotas, estados, medios de pago y comprobantes.

5. Gestión de Alumnos

5.1 Descripción General

El módulo permite registrar y administrar estudiantes. Cada alumno se vincula a una persona, posee legajo único, estado y datos de contacto.

5.2 Operaciones Disponibles

1

Registrar alumno

Completar nombre, apellido, email, DNI, teléfono y datos complementarios. El sistema genera o asigna un legajo.

2

Editar datos

Modificar información personal, domicilio, fecha de nacimiento, biografía o avatar cuando corresponda.

3

Consultar historial

Visualizar cursos, inscripciones, pagos, calificaciones y asistencias asociados.

4

Cambiar estado

Activar o inactivar el alumno sin eliminar su historial académico.

6. Gestión de Profesores

Este módulo administra el plantel docente. Cada profesor puede tener especialidad, idiomas asociados, estado y cursos asignados.

CampoDescripción
EspecialidadIdioma o área principal del profesor.
Idiomas asignadosRelación entre profesor e idiomas habilitados.
Cursos activosCursos que dicta actualmente.
EstadoActivo, inactivo o licencia.

6.1 Procedimiento Básico

1

Crear profesor

Registrar datos personales y especialidad.

2

Asignar idiomas

Seleccionar los idiomas que puede dictar.

3

Asignar curso

Vincular el profesor a uno o más cursos activos.

7. Cursos e Inscripciones

7.1 Módulo Cursos

Permite administrar cursos con idioma, nivel, profesor, aula, horario, cupo máximo y configuración de cuotas habilitadas.

DatoUso
IdiomaDefine la lengua del curso: inglés, francés, alemán, japonés, italiano, chino mandarín o latín.
NivelIndica dificultad o etapa académica.
ProfesorDocente responsable del curso.
AulaEspacio asignado y capacidad.
Cuotas habilitadasConceptos que el alumno puede pagar en ese curso.

7.2 Procedimiento para Inscribir Alumno

1

Seleccionar alumno

Buscar el alumno registrado en el sistema.

2

Seleccionar curso

Elegir el curso disponible según idioma, nivel y cupo.

3

Confirmar inscripción

Guardar la inscripción con fecha y estado activo.

4

Verificar acceso

Confirmar que el alumno puede consultar el curso en su perfil o classroom.

8. Pagos y Comprobantes

8.1 Descripción General

El módulo de pagos permite registrar cuotas y matrículas asociadas a alumnos y cursos. Soporta medios de pago como efectivo, transferencia y tarjeta de crédito.

8.2 Procedimiento para Registrar Pago

1

Seleccionar alumno y curso

Buscar el alumno y elegir el curso correspondiente.

2

Seleccionar concepto

Elegir matrícula o cuota mensual disponible para ese curso.

3

Completar datos de pago

Ingresar monto, medio de pago y observaciones si corresponde.

4

Confirmar operación

El sistema registra el pago y genera el comprobante PDF descargable.

8.3 Estados de Pago

EstadoDescripción
en_procesoPago pendiente de confirmación.
pagadoPago confirmado y registrado.
anuladoPago cancelado por administración.

9. Classroom

9.1 Descripción General

Classroom es el entorno virtual de aprendizaje del sistema. Permite que profesores publiquen contenido y que alumnos interactúen con tareas, anuncios, encuestas, calendario, recursos y chats.

9.2 Funciones del Profesor

Tareas

  • Crear tareas
  • Definir fecha límite
  • Adjuntar archivos o enlaces
  • Revisar entregas
  • Calificar y comentar

Anuncios

  • Publicar novedades
  • Marcar importancia
  • Adjuntar enlaces
  • Crear encuestas
  • Responder comentarios

Evaluación

  • Registrar parcial 1
  • Registrar parcial 2
  • Registrar final
  • Tomar asistencia
  • Consultar historial

9.3 Funciones del Alumno

  • Ver cursos en los que se encuentra inscrito.
  • Consultar tareas asignadas, fechas límite y estado de entrega.
  • Entregar tareas con texto o archivo adjunto.
  • Ver calificaciones y comentarios.
  • Leer anuncios y participar en comentarios.
  • Responder encuestas.
  • Consultar calendario y recursos.
  • Chatear con profesores o compañeros del curso.

9.4 Procedimiento para Entregar Tarea

1

Ingresar al curso

Desde Classroom, seleccionar el curso correspondiente.

2

Abrir tarea

Revisar consigna, fecha límite y archivos adjuntos.

3

Cargar entrega

Escribir contenido o adjuntar archivo según lo solicitado.

4

Enviar

Confirmar la entrega y esperar revisión del profesor.

10. Chat y Soporte

10.1 Descripción General

El sistema de chat permite comunicación en tiempo real entre usuarios y administración. También existen conversaciones internas de Classroom entre alumnos y profesores por curso.

10.2 Tipos de Usuario en Chat

TipoDescripción
InvitadoPuede iniciar una conversación de soporte sin cuenta activa.
AlumnoChat vinculado a su cuenta de alumno.
ProfesorChat vinculado a su cuenta docente.
AdministradorAtiende y gestiona conversaciones entrantes.

10.3 Estados de Conversación

EstadoDescripción
PendienteConversación iniciada y aún no atendida.
ActivaConversación en curso.
ResueltaConsulta solucionada.
CerradaConversación finalizada.

10.4 Funciones Disponibles

  • Envío y recepción de mensajes en tiempo real.
  • Archivos adjuntos como imágenes y PDF.
  • Contador de mensajes no leídos.
  • Historial persistente de conversaciones.
  • Indicadores de estado y atención.

11. Seguridad, Perfil y Salida

11.1 Perfil de Usuario

Desde el perfil, el usuario puede consultar sus datos personales, avatar, información académica y datos relacionados con su cuenta. Según el rol, puede acceder a información adicional como cursos, pagos, calificaciones o estadísticas.

11.2 Seguridad y Privacidad

El sistema incluye secciones para recuperación de cuenta, cambio de contraseña, configuración de privacidad, descarga de datos, eliminación de cuenta, alertas de acceso, dispositivos activos, códigos de recuperación y reportes de seguridad.

Ante una sospecha de acceso no autorizado, el usuario debe contactar inmediatamente a administración y cambiar sus credenciales siguiendo el flujo de seguridad correspondiente.

11.3 Barra de Navegación

La barra superior o menú principal permite acceder a módulos, perfil, notificaciones, ayuda, documentación y cierre de sesión. Las opciones visibles dependen del rol autenticado.

11.4 Salir del Sistema

1

Abrir menú de usuario

Hacer clic en el nombre, avatar o botón de cuenta.

2

Seleccionar Cerrar sesión

El sistema elimina la sesión local y bloquea el acceso privado.

3

Confirmar redirección

El usuario vuelve a la pantalla de inicio de sesión o página principal.
