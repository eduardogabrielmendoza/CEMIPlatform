Este manual está dirigido a usuarios que interactúan con CEMI Sistema Gestor. Su propósito es explicar el funcionamiento de la plataforma en lenguaje operativo, con pasos concretos, advertencias y representaciones visuales de cada módulo.

2. Introducción y acceso al sistema

2.1 Introducción general

CEMI Sistema Gestor es una plataforma web para administrar el Centro Municipal de Idiomas. Integra gestión de alumnos, profesores, cursos, idiomas, niveles, aulas, inscripciones, pagos, comprobantes, calificaciones, asistencias, classroom, chat, notificaciones, comunidad, documentación y seguridad.

El sistema se utiliza desde un navegador web y muestra funciones distintas según el perfil del usuario. Un administrador accede a datos institucionales y operaciones de gestión; un profesor opera cursos, tareas, asistencias y calificaciones; un alumno consulta su información académica; y un invitado accede a páginas públicas o soporte inicial.

2.2 Audiencia y perfiles de usuario

Administrador

Gestiona alumnos, profesores, cursos, pagos, usuarios, soporte, reportes y configuración.

Profesor

Administra classroom, tareas, recursos, anuncios, asistencias, calificaciones y comunicación académica.

Alumno

Consulta cursos, pagos, comprobantes, tareas, entregas, anuncios, notas y comunidad.

Invitado

Consulta información pública, oferta académica y puede iniciar contacto por soporte.

3. Gestión de autenticación y cuentas

3.1 Pantalla de inicio de sesión

La pantalla de inicio de sesión valida la identidad del usuario. Protege las secciones privadas y permite que cada perfil acceda únicamente a las funciones habilitadas. El sistema revisa formato de datos, existencia de cuenta, contraseña, estado del usuario y perfil asignado.

3.3 Procedimiento de inicio de sesión

  1. Verificar que se está usando el sitio oficial de CEMI.
  2. Ingresar usuario o correo registrado.
  3. Ingresar contraseña respetando mayúsculas, minúsculas y símbolos.
  4. Presionar Ingresar.
  5. Si el sistema muestra un mensaje de error, revisar los datos o usar recuperación de contraseña.

El registro de cuenta permite crear un acceso inicial. Según la política institucional, el usuario puede quedar pendiente de validación o ser asociado luego a un perfil de alumno, profesor o administrador.

3.6 Recuperación de contraseña

  1. Seleccionar Recuperar contraseña.
  2. Ingresar el correo asociado a la cuenta.
  3. Revisar el mensaje recibido y copiar el código de verificación.
  4. Escribir la nueva contraseña y confirmarla.
  5. Iniciar sesión nuevamente con la clave actualizada.
Advertencia: nunca compartir códigos de recuperación ni enviarlos por chat. Si un usuario sospecha que su cuenta fue expuesta, debe informar a administración.

5. Gestión académica: alumnos, profesores y cursos

5.1 Descripción general

La gestión académica permite mantener los datos centrales de CEMI. Administración puede registrar alumnos, profesores, cursos, idiomas, niveles, aulas, horarios, cupos y estados. Estos datos alimentan otros módulos: inscripciones, pagos, classroom, asistencias y calificaciones.

5.2 Alta de alumno

  1. Ingresar al panel administrativo.
  2. Abrir el módulo Alumnos.
  3. Seleccionar Nuevo alumno.
  4. Completar nombre, apellido, DNI, correo, teléfono, domicilio y datos académicos requeridos.
  5. Verificar que el legajo o identificación no esté duplicado.
  6. Guardar el registro y revisar que figure en el listado.

5.3 Alta de profesor

  1. Abrir el módulo Profesores.
  2. Completar datos personales y correo.
  3. Indicar especialidad o idioma principal.
  4. Definir estado inicial del profesor.
  5. Guardar y, si corresponde, asociar credenciales de acceso.

5.4 Creación de curso

Un curso reúne idioma, nivel, profesor, aula, horario, cupo y estado. Antes de crearlo conviene tener cargados los catálogos de idiomas, niveles, aulas y profesores.

5.5 Edición e inactivación

La edición permite corregir datos sin eliminar historial. Si un alumno, profesor o curso deja de estar disponible, se recomienda cambiar su estado a inactivo en lugar de borrar registros vinculados a pagos, inscripciones o actividad académica.

6. Inscripciones y cupos

6.1 Descripción general

La inscripción vincula un alumno con un curso activo. Permite controlar cupos, estados académicos y asociación posterior con pagos, calificaciones y asistencias. Es una operación administrativa crítica porque define qué alumno pertenece a qué curso.

6.2 Procedimiento de inscripción

  1. Abrir el módulo Inscripciones.
  2. Buscar al alumno por nombre, DNI, correo o legajo.
  3. Seleccionar curso activo.
  4. Revisar cupo, horario, aula, profesor y nivel.
  5. Confirmar inscripción.
  6. Verificar que el alumno aparezca en la lista del curso.

6.3 Estados de inscripción

EstadoSignificado
ActivaEl alumno cursa normalmente y aparece en listados académicos.
PendienteLa inscripción requiere revisión administrativa o pago asociado.
InactivaEl alumno ya no participa del curso, pero se conserva historial.
AnuladaLa inscripción fue creada por error y debe quedar documentada.

6.4 Control de cupos

El cupo evita sobrecargar cursos. Antes de confirmar una inscripción, administración debe verificar alumnos inscritos, capacidad del aula y disponibilidad del profesor. Si el cupo está completo, se recomienda crear lista de espera o derivar a otro curso.

7. Pagos, cuotas y comprobantes

7.1 Descripción general

El módulo de pagos registra operaciones financieras asociadas a alumnos y cursos. Permite documentar matrícula, cuotas, medios de pago, referencias, estados y comprobantes PDF. No funciona como caja comercial; su finalidad es mantener trazabilidad administrativa de pagos académicos.

7.2 Registro de pago

  1. Abrir el módulo Pagos.
  2. Buscar y seleccionar alumno.
  3. Seleccionar curso o concepto correspondiente.
  4. Indicar monto, medio de pago y referencia si existe.
  5. Elegir estado: pagado, en proceso o anulado.
  6. Guardar el registro.
  7. Generar o consultar comprobante PDF.

7.3 Medios y estados

7.4 Anulación o corrección de pago

Si un pago fue cargado por error, administración debe corregirlo conservando trazabilidad. La opción recomendada es cambiar estado, registrar motivo y, cuando corresponda, crear un nuevo registro correcto. No se recomienda eliminar pagos con impacto administrativo.

Control: antes de anular un pago, revisar alumno, curso, concepto, monto, medio de pago y comprobante asociado.

8. Classroom CEMI

8.1 Descripción general

Classroom CEMI es el entorno académico donde profesores y alumnos gestionan tareas, entregas, anuncios, recursos, encuestas, calendario, comentarios y comunicación del curso. Está vinculado con cursos reales y respeta los permisos del usuario autenticado.

8.2 Funciones del profesor

  • Publicar tareas con título, consigna, fecha límite y archivos adjuntos.
  • Revisar entregas de alumnos y registrar devoluciones académicas.
  • Publicar anuncios para el curso.
  • Subir recursos o enlaces de estudio.
  • Crear encuestas y revisar respuestas.
  • Registrar calificaciones y asistencias.
  • Comunicarse con alumnos mediante chat académico.

8.3 Funciones del alumno

  • Ingresar a cursos activos.
  • Consultar tareas, fechas límite y recursos.
  • Enviar entregas con texto o archivo.
  • Consultar calificaciones, comentarios y estado de entrega.
  • Leer anuncios y responder encuestas.
  • Usar chat académico o soporte cuando corresponda.

8.4 Procedimiento para publicar tarea

  1. Ingresar como profesor.
  2. Abrir el curso asignado.
  3. Seleccionar Nueva tarea.
  4. Completar título, descripción, fecha límite y adjuntos.
  5. Publicar y verificar que aparezca en el listado del curso.

8.5 Procedimiento para entregar tarea

  1. Ingresar como alumno.
  2. Abrir el curso correspondiente.
  3. Seleccionar la tarea pendiente.
  4. Leer consigna y adjuntar respuesta o archivo.
  5. Presionar Enviar entrega y verificar estado.

9. Calificaciones, asistencias y reportes

9.1 Calificaciones

El módulo de calificaciones permite registrar notas parciales, finales y observaciones por alumno y curso. El profesor puede cargar notas de sus cursos asignados, mientras que administración puede consultar información consolidada.

9.2 Registro de asistencia

  1. Seleccionar curso y fecha.
  2. Verificar listado de alumnos inscritos.
  3. Marcar presente, ausente, tardanza o justificado.
  4. Agregar observación si corresponde.
  5. Guardar asistencia y revisar resumen.

9.3 Reportes administrativos

Los reportes permiten revisar información institucional. Pueden incluir alumnos por curso, profesores asignados, pagos por período, cuotas pendientes, asistencias, calificaciones y actividad de classroom.

10.1 Chat de soporte

El chat de soporte permite que invitados, alumnos o usuarios registrados realicen consultas. Administración puede responder, cambiar estados de conversación y conservar seguimiento de cada caso.

10.2 Notificaciones

Las notificaciones informan eventos relevantes: nueva tarea, entrega revisada, anuncio publicado, pago registrado, mensaje de soporte o cambio de estado. El usuario debe revisarlas con frecuencia para evitar omitir acciones importantes.

10.3 Comunidad CEMI

La comunidad permite consultar novedades, publicaciones e información institucional. Puede ser utilizada por alumnos para mantenerse informados y por administración para fortalecer la comunicación interna.

11. Administración de usuarios y seguridad

11.1 Gestión de usuarios

Disponible para administradores. Permite crear, consultar, editar, activar o inactivar usuarios. Cada usuario debe estar asociado a una persona y a un perfil. El perfil define qué módulos puede utilizar.

11.3 Seguridad de cuenta

  • Usar contraseñas personales y no reutilizadas.
  • No compartir credenciales por mensajes o capturas.
  • Solicitar cambio de contraseña si se sospecha acceso indebido.
  • Cerrar sesión en dispositivos compartidos.
  • Contactar a administración ante cambios de rol o estado.

11.4 CEMI Key

CEMI Key es un acceso de seguridad complementario para perfiles habilitados. Su uso permite validar identidad en flujos específicos y reforzar el control de acceso. Si el usuario pierde o expone su clave, debe solicitar regeneración a administración.

  • Revisar los datos antes de guardar altas o modificaciones.
  • Usar estados inactivos antes que eliminar información con historial.
  • Registrar observaciones en correcciones administrativas.
  • Verificar alumno, curso y concepto antes de confirmar pagos.
  • Consultar notificaciones y mensajes pendientes al iniciar la jornada.
  • Reportar errores, accesos sospechosos o datos inconsistentes.
