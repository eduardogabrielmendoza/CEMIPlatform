3. Resumen Ejecutivo

3.1 Breve descripción del proyecto

El presente Trabajo Final Integrador consiste en el diseño y desarrollo de un Sistema de Gestión Académica Integral para el Centro de Estudios Multilingüe Internacional (CEMI), implementado como aplicación web con arquitectura cliente-servidor.

El sistema tiene como finalidad digitalizar y optimizar los procesos académicos, administrativos, financieros y comunicacionales del centro, permitiendo gestionar alumnos, profesores, cursos, idiomas, niveles, aulas, inscripciones, pagos, calificaciones, asistencias, classroom, comunidad y soporte en tiempo real desde una plataforma centralizada.

La solución incorpora persistencia real mediante base de datos MySQL, autenticación con JWT, contraseñas cifradas, control de acceso por roles, generación de comprobantes PDF, chat con Socket.IO y despliegue en Railway.

3.2 Objetivos principales

El objetivo general del proyecto es desarrollar un sistema web que permita automatizar la gestión operativa de una institución de idiomas, reduciendo tareas manuales y mejorando la trazabilidad de la información.

  • Diseñar una base de datos relacional normalizada para las entidades académicas y administrativas.
  • Implementar operaciones CRUD para alumnos, profesores, cursos, idiomas, niveles, aulas e inscripciones.
  • Desarrollar autenticación, recuperación de cuentas y control de acceso mediante roles.
  • Automatizar pagos, conceptos, cuotas, estados y comprobantes PDF.
  • Implementar un entorno Classroom con tareas, anuncios, encuestas, entregas, calendario, recursos y chat.
  • Registrar calificaciones y asistencias por curso.
  • Incorporar soporte en tiempo real y notificaciones.
  • Aplicar metodología ágil y documentar el proceso de desarrollo.

3.3 Metodología utilizada

El proyecto fue desarrollado con una metodología ágil basada en sprints. El proceso incluyó relevamiento, análisis, diseño de base de datos, implementación backend, implementación frontend, integración, pruebas funcionales, despliegue y documentación final.

Se utilizaron Node.js, Express, MySQL, HTML5, CSS3, JavaScript, Socket.IO, JWT, bcrypt, PDFKit, Cloudinary, SendGrid/Nodemailer, GitHub y Railway.

3.4 Resultados esperados

  • Gestionar datos institucionales desde un panel administrativo.
  • Centralizar alumnos, profesores, cursos e inscripciones.
  • Permitir seguimiento de pagos, cuotas y comprobantes.
  • Facilitar la comunicación académica mediante Classroom y chat.
  • Consultar calificaciones, asistencias, tareas y anuncios desde perfiles diferenciados.
  • Mantener integridad, seguridad y disponibilidad de la información.

3.5 Conclusiones generales

El desarrollo de CEMI permitió integrar conocimientos de programación, base de datos, arquitectura web, seguridad, experiencia de usuario y despliegue en la nube. El resultado es una solución académica completa, documentada y evaluable, alineada con las competencias de la Tecnicatura Universitaria en Programación.

4. Introducción

4.1 Contexto y antecedentes

La digitalización de procesos educativos es una necesidad creciente para instituciones que administran cursos, docentes, alumnos, pagos y comunicación diaria. En centros de idiomas, el uso de registros dispersos o canales informales dificulta la trazabilidad y demora la toma de decisiones.

CEMI se ubica en este contexto como una solución web orientada a centralizar la gestión académica y ofrecer un entorno virtual propio para alumnos, profesores y administración.

4.2 Justificación

La implementación de un sistema integral responde a la necesidad de unificar información en una única plataforma, evitando duplicidad de registros, errores manuales y pérdida de datos. Desde una perspectiva académica, el proyecto permite aplicar de manera articulada:

  • Programación modular en backend y frontend.
  • Diseño y normalización de bases de datos relacionales.
  • Arquitectura cliente-servidor con API REST.
  • Seguridad mediante autenticación, roles y cifrado.
  • Comunicación en tiempo real mediante WebSockets.
  • Metodologías ágiles y documentación técnica.

4.3 Objetivo General

Implementar un Sistema de Gestión Académica Integral para CEMI, destinado a digitalizar, centralizar y optimizar los procesos académicos, administrativos, financieros y de comunicación del centro, fortaleciendo la organización institucional y la experiencia de alumnos y profesores.

4.4 Objetivos Específicos

  • Digitalizar la gestión académica: centralizar alumnos, profesores, cursos, niveles, idiomas y aulas en una base de datos estructurada.
  • Optimizar inscripciones: vincular alumnos y cursos con estados, cupos y fechas.
  • Automatizar pagos: registrar cuotas, medios de pago, estados y comprobantes PDF.
  • Implementar Classroom: administrar tareas, entregas, anuncios, encuestas, calendario, recursos y conversaciones.
  • Controlar rendimiento académico: gestionar calificaciones y asistencias por curso.
  • Mejorar comunicación: incorporar chat de soporte, chat de classroom y notificaciones.
  • Asegurar escalabilidad: permitir futuras ampliaciones de módulos, cursos y servicios.

5. Estado del Arte

5.1 Contexto tecnológico actual

Las instituciones educativas utilizan cada vez más sistemas web para administrar información académica, pagos y entornos virtuales. Plataformas como Moodle, Google Classroom y sistemas administrativos SaaS resuelven partes del problema, pero suelen requerir integración externa, suscripciones, configuración compleja o no se adaptan completamente a la operatoria local de un centro de idiomas.

5.2 Sistemas existentes y comparativa

Las soluciones disponibles suelen incluir gestión de cursos, aulas virtuales, comunicación o reportes, pero no siempre integran administración académica, pagos, comprobantes, soporte, comunidad y seguridad en una misma plataforma.

SaaS educativos

  • Acceso remoto
  • Actualizaciones externas
  • Costos recurrentes
  • Menor control del código

Aulas virtuales aisladas

  • Buen manejo de tareas
  • Poca gestión financiera
  • Integración administrativa limitada
  • Dependencia de cuentas externas

Aplicación web CEMI

  • Gestión académica integrada
  • Pagos y comprobantes
  • Classroom propio
  • Código evaluable y modular

5.3 Enfoques tecnológicos actuales

El proyecto adopta una aplicación web modular porque permite acceso multiplataforma, separación de responsabilidades, escalabilidad y mantenimiento ordenado. El backend expone rutas API, el frontend consume los servicios y la base de datos preserva la integridad de la información.

5.4 Modelado de datos y normalización

El uso de MySQL permite modelar entidades con relaciones claras entre personas, usuarios, alumnos, profesores, cursos, pagos, calificaciones, asistencias, classroom y chat. La normalización reduce redundancias, evita inconsistencias y facilita consultas confiables.

5.5 Seguridad y control de acceso

La seguridad se aborda con JWT para sesiones, bcrypt para contraseñas, Helmet para encabezados, CORS configurado, rate limiting y roles diferenciados. El sistema también incorpora páginas de seguridad, privacidad, recuperación de cuenta, datos personales y reportes.

5.6 Fundamentación del aporte del proyecto

  • Integra gestión académica, financiera y classroom en una sola plataforma.
  • Permite evaluar código, arquitectura, base de datos y documentación.
  • Se adapta a un centro de idiomas con múltiples cursos, niveles e idiomas.
  • Incorpora comunicación en tiempo real y soporte con adjuntos.
  • Contempla despliegue real en Railway y servicios externos.

6. Descripción del Proyecto

6.1 Problemática detectada

  • Falta de centralización de datos académicos y administrativos.
  • Dificultad para controlar inscripciones, cupos, pagos y comprobantes.
  • Ausencia de una plataforma classroom propia integrada al sistema administrativo.
  • Necesidad de comunicación ordenada entre alumnos, profesores y administración.
  • Falta de trazabilidad en consultas, tareas, anuncios, calificaciones y asistencias.

6.2 Solución propuesta

7. Metodología

7.1 Enfoque metodológico

Se adoptó un enfoque ágil e iterativo, organizando el trabajo en fases funcionales y revisiones progresivas. Cada etapa integró análisis, diseño, implementación, validación y documentación.

7.2 Técnicas y herramientas utilizadas

Backend

  • Node.js
  • Express
  • MySQL2
  • JWT
  • Bcryptjs
  • Socket.IO
  • Helmet y CORS
  • PDFKit y ExcelJS

Frontend

  • HTML5
  • CSS3
  • JavaScript
  • Lucide Icons
  • Diseño responsive
  • PWA

Servicios

  • Railway
  • Cloudinary
  • SendGrid/Nodemailer
  • GitHub
  • Visual Studio Code

7.3 Diseño del sistema y arquitectura

Frontend: páginas HTML, CSS y JavaScript que consumen la API y presentan dashboards, classroom, perfiles, seguridad y documentación.

Backend: servidor Express con rutas para auth, alumnos, profesores, cursos, pagos, classroom, chat, comunidad, seguridad y estado del sistema.

Base de datos: MySQL con entidades relacionadas para gestión académica, pagos, comunicación y auditoría funcional.

7.4 Desarrollo e implementación

El desarrollo se realizó de forma incremental. Primero se definió la base de datos y autenticación; luego se implementaron dashboards y CRUD; posteriormente pagos, classroom, chat, seguridad, comunidad, documentación y despliegue.

7.5 Pruebas e integración

Se validaron flujos principales: inicio de sesión, registro y activación de cuenta, administración de alumnos y profesores, cursos, pagos, classroom, notificaciones, chats, rutas API y visualización de documentación.

10. Resultados Esperados

10.1 Resultados y beneficios

El Sistema de Gestión Académica CEMI permite digitalizar y centralizar las operaciones de una institución de idiomas, reduciendo errores administrativos y mejorando la disponibilidad de información para alumnos, profesores y administración.

  • Información académica consolidada y accesible.
  • Mejor control de inscripciones, pagos y comprobantes.
  • Seguimiento de rendimiento mediante calificaciones y asistencias.
  • Classroom integrado para actividades, anuncios y recursos.
  • Comunicación en tiempo real mediante chats y notificaciones.
  • Mayor seguridad y trazabilidad de operaciones.

10.2 Impacto académico

El proyecto evidencia la aplicación práctica de conocimientos de ingeniería de software, programación web, bases de datos, seguridad, despliegue y documentación. Además, permite evaluar una solución real con arquitectura completa y alcance institucional.
