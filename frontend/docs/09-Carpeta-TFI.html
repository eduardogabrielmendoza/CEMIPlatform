3. Resumen Ejecutivo

3.1 Breve descripción del proyecto

El presente Trabajo Final Integrador consiste en el diseño y desarrollo de un Sistema de Gestión Académica Integral para el Centro de Estudios Multilingüe Internacional (CEMI), implementado como aplicación web con arquitectura cliente–servidor.

El sistema tiene como finalidad digitalizar y optimizar los procesos académicos, administrativos y de comunicación del centro de idiomas, permitiendo gestionar alumnos, profesores, cursos, inscripciones, pagos, calificaciones, asistencias y un entorno virtual Classroom en un ecosistema centralizado y seguro.

La solución incorpora persistencia real mediante base de datos relacional MySQL, autenticación JWT, chat en tiempo real con Socket.IO y control de acceso basado en roles.

3.2 Objetivos principales

  • Diseñar una base de datos relacional normalizada con más de 25 entidades.
  • Implementar operaciones CRUD completas para todas las entidades principales.
  • Desarrollar autenticación y control de acceso mediante JWT y roles.
  • Automatizar el control de inscripciones, pagos y calificaciones.
  • Implementar un entorno virtual Classroom completo.
  • Desarrollar chat de soporte en tiempo real con Socket.IO.
  • Generar comprobantes de pago en formato PDF.

3.3 Metodología utilizada

El proyecto fue desarrollado utilizando una metodología ágil basada en Scrum, organizada en sprints iterativos. Se utilizaron tecnologías como Node.js, Express, MySQL, HTML5, CSS3, JavaScript y Socket.IO.

3.4 Resultados esperados

  • Gestionar alumnos, profesores, cursos e inscripciones.
  • Automatizar el registro y seguimiento de pagos con comprobantes PDF.
  • Controlar calificaciones y asistencias en tiempo real.
  • Proveer un entorno Classroom con tareas, anuncios y chat.
  • Garantizar seguridad mediante JWT, bcrypt y Helmet.
  • Mantener persistencia e integridad de datos con MySQL.

4. Introducción

4.1 Contexto y antecedentes

La digitalización de procesos académicos constituye actualmente un factor determinante en la competitividad de las instituciones educativas. La incorporación de sistemas informáticos permite mejorar la organización interna, optimizar el control de recursos y disponer de información confiable para la toma de decisiones.

En el ámbito de los centros de idiomas, persiste el uso de métodos manuales o herramientas aisladas para gestionar inscripciones, controlar pagos y administrar la comunicación académica. Esta modalidad genera inconsistencias en los datos, falta de trazabilidad y limitaciones en la generación de reportes.

4.2 Justificación

La implementación de un sistema de gestión integral responde a la necesidad de centralizar la información operativa en una única plataforma. Desde una perspectiva académica, el proyecto se justifica como instancia integradora aplicando:

  • Programación estructurada y modular.
  • Diseño y normalización de bases de datos.
  • Arquitectura cliente–servidor con API RESTful.
  • Comunicación en tiempo real con WebSockets.
  • Seguridad y control de acceso basado en roles.

4.3 Objetivo General

Implementar un Sistema de Gestión Académica Integral para CEMI, destinado a digitalizar, centralizar y optimizar los procesos académicos, administrativos y de comunicación del centro. El sistema busca modernizar la gestión de inscripciones, pagos, calificaciones, asistencias y la interacción alumno-profesor mediante un entorno virtual completo.

4.4 Objetivos Específicos

  • Digitalizar la gestión académica: Mediante una plataforma que centralice toda la información en una base de datos estructurada.
  • Optimizar el control de inscripciones: Permitiendo gestionar inscripciones con validación de cupos y estados.
  • Automatizar el proceso de pagos: Registrando cada transacción con múltiples medios de pago y generando comprobantes PDF.
  • Implementar Classroom virtual: Con tareas, anuncios, encuestas, calendario, chat y recursos compartidos.
  • Generar reportes automáticos: De inscripciones, pagos, calificaciones y asistencias.
  • Diseñar una interfaz moderna y responsive: Con dark mode, animaciones y experiencia de usuario premium.
  • Asegurar la escalabilidad: Previendo ampliaciones como nuevos idiomas, niveles y funcionalidades.

5. Estado del Arte

5.1 Contexto tecnológico actual

Las instituciones educativas enfrentan el desafío de adaptarse a herramientas tecnológicas que permitan una gestión eficiente de sus procesos académicos. Plataformas como Google Classroom, Moodle y Canvas ofrecen soluciones parciales, pero su alto costo o complejidad limitan su adopción por parte de centros de idiomas pequeños y medianos.

5.2 Sistemas existentes

Las soluciones existentes no están adaptadas a la realidad de centros de idiomas locales, requieren suscripciones mensuales, no permiten personalización del código y no integran gestión académica con gestión financiera en una única plataforma.

5.3 Enfoques tecnológicos

SaaS en la nube

  • Acceso remoto
  • Actualizaciones automáticas
  • Dependencia del proveedor
  • Costos recurrentes

Sistemas tradicionales

  • Funcionamiento local
  • Sin conexión requerida
  • Limitaciones de escalabilidad
  • Sin acceso remoto

Web apps modulares ✓

  • Accesibilidad multiplataforma
  • Control estructural
  • Separación de responsabilidades
  • Escalabilidad futura

5.4 Seguridad y control de acceso

La autenticación basada en JSON Web Token (JWT) se ha consolidado como estándar. El sistema CEMI implementa:

  • Verificación de identidad mediante JWT.
  • Control de acceso por roles (RBAC): admin, profesor, alumno.
  • Encriptación de contraseñas con bcrypt.
  • Protección de headers con Helmet.
  • Rate limiting para prevención de ataques.
  • Validación de dominio de email institucional.

6. Descripción del Proyecto

6.1 Problemática Detectada

  • Falta de centralización de datos académicos y administrativos.
  • Procesos manuales para inscripciones y control de pagos.
  • Ausencia de plataforma virtual para comunicación alumno-profesor.
  • Dificultad para obtener reportes consolidados del centro.
  • Carencia de sistema de notificaciones y seguimiento de actividades.

6.2 Solución Propuesta

Se desarrolló un Sistema de Gestión Académica Integral con arquitectura cliente–servidor, que incluye los siguientes módulos:

Gestión Académica

  • Alumnos (CRUD + legajo)
  • Profesores (especialidades)
  • Cursos (idioma, nivel, horario)
  • Inscripciones

Gestión Financiera

  • Pagos (matrícula, cuotas)
  • Medios de pago múltiples
  • Comprobantes PDF
  • Registros de auditoría

Evaluación

  • Calificaciones (P1, P2, Final)
  • Asistencias (4 estados)
  • Historial por alumno
  • Reportes por curso

Classroom Virtual

  • Tareas con entregas
  • Anuncios y encuestas
  • Calendario de eventos
  • Chat alumno-profesor

Comunicación

  • Chat soporte (Socket.IO)
  • Notificaciones en tiempo real
  • Emails transaccionales
  • Sistema de comunidad

Administración

  • Panel admin completo
  • Estadísticas del sistema
  • Gestión de usuarios
  • Depuración y backup

7. Metodología

7.1 Enfoque Metodológico

Se adoptó una metodología ágil basada en Scrum, organizada en ciclos iterativos. El desarrollo se dividió en fases de análisis, diseño, implementación, pruebas y documentación.

7.2 Tecnologías Implementadas

Backend

  • Node.js + Express 5
  • MySQL2 (mysql2)
  • JWT (jsonwebtoken)
  • Bcryptjs
  • Socket.IO 4
  • Helmet + CORS
  • Morgan + Rate Limit
  • PDFKit
  • ExcelJS

Frontend

  • HTML5 semántico
  • CSS3 con variables
  • JavaScript vanilla
  • Lucide Icons
  • Diseño responsive
  • PWA (manifest.json)

Servicios

  • SendGrid (emails)
  • Cloudinary (archivos)
  • Railway (deploy)
  • MySQL en la nube

7.3 Arquitectura del Sistema

Arquitectura de 3 capas:

Frontend → HTML/CSS/JS → Consume API REST

Backend → Node.js/Express → 31 archivos de rutas, middleware, utilidades

Base de Datos → MySQL → 25+ tablas con integridad referencial y migraciones automáticas

10. Resultados Esperados

10.1 Resultados y Beneficios

El Sistema de Gestión Académica CEMI permitió digitalizar por completo las operaciones del centro de idiomas, eliminando la dependencia de procesos manuales y reduciendo errores administrativos.

  • Implementación de un sistema funcional con 25+ entidades en base de datos.
  • Persistencia real de datos mediante MySQL con integridad referencial.
  • Control de acceso seguro mediante JWT con 3 roles diferenciados.
  • Entorno virtual Classroom completo con tareas, anuncios y chat.
  • Chat de soporte en tiempo real con Socket.IO.
  • Generación de comprobantes de pago en PDF.
  • Sistema de notificaciones en tiempo real por tipo de evento.

10.2 Impacto Académico

  • Integración interdisciplinaria de contenidos de la carrera.
  • Aplicación de metodologías ágiles en desarrollo real.
  • Desarrollo de competencias en arquitectura cliente-servidor.
  • Implementación de comunicación en tiempo real con WebSockets.
  • Aplicación práctica de seguridad web (JWT, bcrypt, Helmet).
